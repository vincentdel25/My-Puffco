Setup & troubleshooting
  1. Replace the old index.html in your existing GitHub repository with this file and commit it.
  2. Open your existing GitHub Pages website in Bluefy. Confirm the title says Phase 2B.2. Refresh if it still shows Phase 1.
  3. Close other Puffco controllers, wake your Peak Pro, and tap Connect Peak Pro. Choose your device.
  4. Keep Bluefy in the foreground until status appears. Tap Copy log after the first status refresh.

The picker shows all nearby devices so a changed device name will not hide your Peak Pro. Choose your own Peak Pro. This version requests the Lorax service identified in your log. It subscribes to replies and events, reads the protocol limits, authenticates, and requests three status paths.

A failed handshake stops status requests. A transport timeout disconnects the device; reconnect to retry. Logs include the Bluetooth device name and raw values, which may contain identifiers. No logs are sent to a server by this page.

Protocol reference: PuffcoPC, commit b8ebc2499ab3f3407822077fd47c16ff57392771. This is an independent JavaScript implementation of its documented packet layout.
